# PoC-6：悬浮条高度变化呈现（三式对照）

**目的**：为 `floatbar-visual` §6.4「高度过渡动画：加 / 不加（建议 120ms）」拍板提供实机证据。

现实现（③ 逐帧跟随）把「丝滑」押在「每帧对原生窗口发 InnerSize」上，合成器在窗口已变、新帧未出处拉伸旧帧——四轮调参不收敛的根因。本探针把三种呈现做成可切换，对照「每次高度变化只做 1 次原生 resize」是否干净。

## 运行

```bash
cargo run --release --manifest-path scripts/poc/poc6_height_resize/Cargo.toml
```

窗口出现在屏幕左上区域（700 宽，空态 176 高）。**自动演示默认开启**：循环播放「两种放置 × 三式」的高度变化，顶部蓝色横幅显示当前播放的阶段（如「③ 逐帧跟随（现状）· 默认放置 · 长到 6 行」），只需盯着看变化瞬间即可。

## 键位

| 键 | 作用 |
|---|---|
| D | 暂停 / 继续自动演示（默认开） |
| 空格 | 行数循环 0→1→…→6→0（模拟结果行数变化） |
| ↑ / ↓ | 行数 ±1 |
| 1 / 2 / 3 | 呈现方式：① 瞬跳 / ② 窗内平滑 / ③ 逐帧跟随（现状） |
| G | 切换「顶左钉住」（`NSView.layerContentsPlacement = TopLeft`：resize 时旧帧裁切而非缩放） |
| A | 自动循环（900ms 一次变化，便于反复观察那 1 帧） |
| P | 暂停自动循环；R 复位 |

任何手动键（空格/↑↓/1/2/3/G/A/P/R）都会接管并暂停自动演示。

## 观察点

1. **每次高度变化瞬间**：面板边缘 / 文字有无「拉伸、重影、闪一下」的一帧。面板顶部**红标** = 刚刚发生原生 resize，便于对时。
2. **② 窗内平滑**：增长时窗口先撑、面板平滑长满；收缩时内容先收、窗口随后一步收到位。过渡期窗口比面板大（透明区），静止时窗口 = 面板。
3. **G 变体**：同一操作在「顶左钉住」下再走一遍，看第 1 条的伪影是否消失。

## 判读

| 现象 | 结论 |
|---|---|
| ① / ③ 有闪或拉伸，② 无 | 走「窗内平滑」（②）；现状（③）不可用 |
| ① 也干净（或打开 G 后干净） | 可走「瞬跳」（无过渡动画），实现最简 |
| ① ② 都不干净且 G 无效 | 回方案讨论（记录现象 + 附 stderr 日志） |

## 说明

- 数值与配色取自设计稿导出（`悬浮条-深色 / 空态`）：宽 700 / 搜索行 64 / 行 56 间距 2 / 结果区上下 8 / 页脚 38 / 圆角 12 / 空态区 72；行数 n → 面板高 = 176 + (n−1)×58（n≥1）。
- 本探针不改 NSPanel 类（跨 Space 行为与 resize 呈现无关，见 poc1b）；窗口为透明无边框置顶。
- 中文渲染依赖 eframe `system_fonts` 特征（与 app 同一条链路）。
- stderr 日志：每次 resize 的编号 / 高度 / 模式，启动时打印 `wantsLayer` / `layerContentsPlacement` / `redrawPolicy` 诊断行。
