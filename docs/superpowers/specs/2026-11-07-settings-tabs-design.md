# 设置页信息架构：顶部图标标签

- 日期：2026-11-07
- 状态：待评审
- 范围：仅重排设置页信息架构；不改设置项语义、持久化字段与业务流程
- 前置：保存面板目录助手的实验化改动（默认关闭 + 开启确认 + 授权链接）已在工作区实现并验证；实现本设计前先提交，作为基线。

## 1. 背景与问题

设置页目前是单页长列表，包含：通用（字号/自启/语言/保存面板目录助手/两个快捷键/命令行工具）、索引（排除目录/外接磁盘）、关于（版本/更新）。随着保存面板目录助手和命令行工具加入，页面变长、分组混杂：

- 通用页混入实验功能与开发者工具；
- 外接磁盘与排除目录被关于页隔开；
- 快捷键没有独立分组；
- 继续新增功能会进一步拉长页面。

目标：**分组更清晰**，在不改窗口尺寸（620×600）的前提下，引入顶部图标标签作为唯一顶层导航。

## 2. 信息架构

固定 5 个标签，顺序如下：

| 顺序 | 标签 | 图标 | 页面内容 |
|---|---|---|---|
| 1 | 通用 | 滑块 | 字号、语言、开机自启；子分组「快捷键」：唤起快捷键、完整窗口快捷键 |
| 2 | 索引 | 文件夹 + 放大镜 | 子分组「排除目录」：列表 + 添加/恢复默认；子分组「外接磁盘」：主开关 + 卷列表 |
| 3 | 高级 | 终端窗口 | 命令行工具（安装/修复/卸载、路径与 FDA 支持行） |
| 4 | 实验 | 烧瓶 | 保存面板目录助手（实验标识、开关、授权链接、重启提示） |
| 5 | 关于 | 信息圆 | 版本、检查更新、启动时自动检查更新、官网 |

要点：

- 标签栏是唯一顶层导航；页面内不再重复「通用 / 索引 / 关于」大标题，只保留子分组标题（快捷键、排除目录、外接磁盘）。
- 快捷键留在「通用」，不单独占标签；620 宽下 5 个标签已接近上限。
- 「高级」当前只有命令行工具，页面偏空（已接受取舍）。
- 「实验」只放保存面板目录助手；实验功能的行为（默认关闭、开启确认、授权）不变。

## 3. 视觉规格

### 3.1 窗口与几何

- 窗口维持 620×600；标题栏 44pt 不变。
- 标题栏下方为标签栏，高 68pt；内容区约 488pt。
- 5 个标签水平居中；单项 96×52pt，间距 4pt；左右留白约 60pt。
- 图标 26pt，线性描边 1.7，圆头端点；标签文字 11pt（受全局字号倍率影响）。
- 标签栏背景与窗口同色（`window_fill`），底边 1px `divider`；不使用毛玻璃。

### 3.2 选中 / 悬停

- 选中：图标与文字使用系统蓝 `switch_on`；底为 10% 蓝色圆角块（圆角 9）。
- 未选中：图标/文字 `text_secondary`；悬停底 `control_fill`。
- 点击整块 96×52 区域即切换，不要求点中图标。
- 新增 token：`TABBAR_H=68`、`TAB_ITEM_W=96`、`TAB_ICON=26`、`TAB_FONT=11`、`TAB_RADIUS=9`、`tab_selected_fill`（深浅两套，系统蓝低透明度）。

### 3.3 图标

全部为自绘线性图标（与现有 folder/× 图标同风格，不引入 NSImage）：

- 通用：三条横线 + 三个滑钮（偏好设置）
- 索引：文件夹轮廓 + 右下放大镜
- 高级：终端窗口轮廓 + `>_`
- 实验：烧瓶轮廓 + 液面线
- 关于：圆形 + `i`

### 3.4 页面布局

- 标签栏固定不滚动；页面内容使用现有 `CONTENT_PAD (20, 24)`。
- 每页独立滚动区，`id_salt = settings-page-<tab>`；切回时保留各自滚动位置。
- 页内卡片沿用现有行模型（`RowSpec` / `take_row`）、卡片底、圆角、分隔线。
- 索引页条目多时正常滚动；通用页目标是一屏可见，无需滚动。

## 4. 状态与交互

- `SettingsTab`：`General / Index / Advanced / Experimental / About`。
- `SettingsState.active_tab`：默认 `General`；设置窗关闭再打开保留上次标签；App 重启回到通用（不写入 settings.toml）。
- `SettingsData.active_tab` 供纯视图绘制。
- 点击标签触发 `SettingsAction::SelectTab(tab)`：立即切换，无动画；仅重绘内容区。
- 快捷键录制中点击标签：先取消录制，再切换标签；动作顺序固定为 `CancelHotkeyRecord` → `SelectTab`。
- 实验页「当前未授权，点击授权。」保持现有行为：注册并打开系统设置，标签不切换；授权后由监视器自动更新。
- 设置窗关闭 / ⌘W / 红点行为不变。
- 暂不加快捷键（⌘1–⌘5）切页，避免与录制冲突。
- 外部入口（托盘「待授权」等）暂不指定标签，打开设置时沿用上次标签。

## 5. 实现结构

- 新增 `crates/app/src/ui/settings_tabs.rs`：
  - `SettingsTab` 枚举；
  - 标签栏绘制、命中区域、悬停/选中态；
  - 5 个自绘图标；
  - 标签栏几何常量。
- `crates/app/src/ui/settings_view.rs`：
  - `draw_body` 拆成「固定标签栏 + 按 `active_tab` 分发页面」；
  - 现有 general/index/about/volumes 绘制函数按页重组；
  - `SettingsData` 增加 `active_tab`；
  - `SettingsAction` 增加 `SelectTab(SettingsTab)`。
- `crates/app/src/ui/settings.rs`：
  - `SettingsState.active_tab`、快照、动作分发；
  - 标签点击与快捷键取消的顺序。
- `crates/app/src/ui/settings_tokens.rs`：新增标签 token 与 `tab_selected_fill` 深浅两套。
- `crates/app/src/i18n/catalog.rs`：5 个标签中英文；高级/实验页不新增说明文案，页面留白按现有卡片风格处理。

职责边界：`settings_tabs` 只管标签栏视觉与命中；`settings_view` 只管页面绘制；`settings.rs` 只管状态与动作编排。

## 6. 测试

纯逻辑/视图（headless egui）：

- 标签栏：5 项顺序、单项 96×52 命中、选中态颜色、悬停、英文标签。
- 页面映射：每个标签只渲染自己的行；同一行不在两页重复；`active_tab` 控制内容。
- 状态：默认 General；`SelectTab` 更新状态；关闭重开保留；重启回 General。
- 录制取消：录制中点击标签产生 `CancelHotkeyRecord` 后再 `SelectTab`。
- 现有坐标点击测试按页重构：提供 `open_tab(data, tab)` 辅助，先切页再点击。
- 卡片高度/行游标 debug assert 在每页仍成立。

实机（`open release/macEverything.app`）：

- 5 个标签切换、选中态、图标清晰度；
- 通用页一屏可见；索引页长列表滚动；实验页授权链接；关于页更新入口；
- 切换标签不影响未保存的录制/错误提示；
- 深色/浅色主题跟随。

突变验证：新增/修改的测试须临时改坏实现确认变红。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 现有 `settings_view` 大量坐标点击测试依赖整页布局 | 引入 `open_tab` 辅助，按页重构；逐页跑测试 |
| 标签点击与快捷键录制取消顺序错误 | 固定 `CancelHotkeyRecord → SelectTab`，加钉住测试 |
| 每页滚动区 id 串页 | 统一 `settings-page-<tab>`，测试覆盖切页后滚动位置 |
| 5 个标签在 620 宽下拥挤 | 96pt 单项、26pt 图标、11pt 文字；实机截图确认 |
| 高级页只有 CLI，内容偏空 | 接受取舍；页内可加一句说明，不塞无关项 |

## 9. 明确不做

- 侧边栏导航、搜索框、⌘1–⌘5 切页、动画过渡。
- 把标签塞进原生标题栏或改动窗口尺寸。
- 修改设置项语义、持久化结构或托盘/更新/索引业务逻辑。
- 重新设计保存面板目录助手的行为（实验页仅承载现有功能）。

## 10. 验收标准

1. 设置窗顶部出现 5 个图标标签，顺序为 通用 / 索引 / 高级 / 实验 / 关于。
2. 每个标签页只显示对应分组，页面内不再出现顶层「通用/索引/关于」大标题。
3. 通用页一屏可见；索引页可滚动；实验页授权链接可用；关于页更新入口可用。
4. 标签切换保留各自滚动位置；关闭重开保留上次标签；App 重启回通用。
5. 录制快捷键时点击标签先取消录制。
6. 深浅主题、字号倍率下标签栏与页面布局正常。
7. `fmt --check` / `clippy -D warnings` / `cargo test --workspace` 全绿。
