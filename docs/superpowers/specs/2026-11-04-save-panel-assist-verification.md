## 0. 环境准备

1. 关闭旧实例与 daemon（托盘退出；必要时 `pkill -f macEverything`）。
2. `cargo build --release && bash scripts/bundle.sh`，`open release/macEverything.app`。
3. `./target/release/macEverything status` 确认 daemon 在线；`save_panel_assist` 默认 true。
4. 系统设置 → 隐私与安全性 → 辅助功能，授权 **release/macEverything.app**（ad-hoc 重打包会改变签名身份，每次重打包需重新确认授权）。
5. 日志：`log stream --predicate 'process == "macEverything-app"' --info`。

## 1. M0 探针验证（独立于产品链路）

前置：设置里先关掉「保存面板目录助手」开关，避免产品 detector 与探针同时作用。

1. `cargo build -p macEverything-app`
2. `MCE_PANEL_PROBE=1 ./target/debug/macEverything-app 2>&1 | tee /tmp/probe.log`（给 debug 二进制授权）
3. `echo "clip-content" | pbcopy` 预置剪贴板
4. TextEdit 新建 → ⌘⇧S，逐项记录：

| # | 验证点 | 记录 |
|---|---|---|
| ① | 通知选型：`AX 通知 ... AXWindowCreated / AXFocusedWindowChanged` 何者触发；窗口快照是否命中 | |
| ② | 策略 A：`AX set value 成功/失败`；面板是否跳到 /tmp | |
| ③ | post-to-pid：日志区分「⌘⇧G 未生效（焦点仍在 AXTextField）」与「3s 内未定位」 | |
| ⑤ | 输入框定位：`Go-to 输入框已定位`；EDITABLE 值 | |
| ⑥ | 前往按钮 vs Return：按钮 title/desc dump；AXPress 或 Return 哪条生效 | |
| ⑦ | 后台线程 AX 调用无崩溃/无错误 | |
| ⑧ | 用 ⌘O 打开面板重复一轮，记录 open/save 的 subrole/可编辑框/按钮差异 | |

5. 实验后 `pbpaste` 应仍为 `clip-content`。
6. 记录 Get Info/Inspector 是否被探针粗判命中（探针宁滥勿缺，仅取证）。

**回填**：`probe-findings.md` 结论表 + 「对 M1 的影响」段（策略 A/B 默认值、检测通知选型、post 目标、按钮本地化形态）。

## 2. 产品链路冒烟（默认开启 + 已授权）

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | TextEdit 新建 → ⌘⇧S | 1s 内浮层出现在面板右侧（越界下方），无装饰，输入框聚焦；宿主 app 不被激活 |
| 2.2 | 输入 `tmp` | 60ms 防抖后出现目录结果（仅目录，无文件），行内「目录名 — 完整路径」 |
| 2.3 | ↓/↑ | 选中行移动不越界；到底停末项、到顶停首项；**选中行不得滚出可视区**（L5） |
| 2.4 | Enter | 浮层立即隐藏；面板「前往文件夹」跳到 /tmp；焦点回文件名框；剪贴板原样 |
| 2.5 | 再 ⌘⇧S：单击一行、双击另一行 | 单击仅选中；双击 = 选中并跳转 |
| 2.6 | **跳转成功后静置 5s 不操作** | 浮层不得重新出现（阻塞 1 主路径） |
| 2.7 | Esc（浮层 key 时） | 浮层隐藏、面板保持；再按 Esc 面板取消 |
| 2.8 | 重新打开同一面板 | 浮层照常出现（面板关闭后记忆清除） |
| 2.9 | Esc 隐藏后，点击面板文件名框/侧栏制造 AX 变化 | 本次面板存续内浮层不得复现（R1：宽口径 Closed 是否提前解除屏蔽） |
| 2.10 | 同一 app 连续「打开面板 → Esc 关闭 → 重新打开」≥3 次 | 每次重新打开都出现浮层（`handled_pids` 与 `PANEL_PID` 的 Closed 清理） |
| 2.11 | 提交跳转后面板仍开着 → 手动「取消」→ 重新打开同一面板 | 浮层正常出现 |
| 2.12 | 浮层显示时鼠标点面板「取消」 | 浮层同步隐藏 |
| 2.13 | ⌘O 打开面板 → 搜索 → Enter | 打开面板同样可跳转 |
| 2.14 | 深路径（≥6 级） | 跳转成功 |
| 2.15 | 多屏：面板拖到副屏（含负坐标屏） | 浮层出现在同一屏 visibleFrame 内，不被菜单栏/Dock 遮挡 |
| 2.16 | 浮层显示时切到别的 app | 浮层隐藏；切回仍开着的面板时记录是否重现 |
| 2.17 | 中文输入法：拼音组合中按 Enter / 组合中按 Esc / 上屏后按 Enter | 组合中不跳转、不关浮层；上屏后 Enter 才跳转（IME 防护） |
| 2.18 | ⌘W / 系统关闭请求（浮层显示时） | 浮层以 dismiss 语义隐藏 |

## 3. 错误路径

| # | 操作 | 预期 |
|---|---|---|
| 3.1 | Enter 后在「前往文件夹」sheet 按 Esc | 跳转中止；剪贴板恢复原件；不粘贴文件名框、不触发保存；面板停在原目录 |
| 3.2 | 剪贴板含富文本/图片/文件后跳转 | 纯文本场景原样还原；富文本会降级/丢失（L1，记录实际） |
| 3.3 | daemon 停止后 ≤30s 开面板 | 设计预期不出浮层；记录缓存陈旧窗口内实际行为（L11） |
| 3.4 | daemon 停止且 >30s 后开面板 | 不出浮层 |
| 3.5 | daemon 离线时打开面板并保持，中途启动 daemon | 记录是否直到关闭/重开面板才出现（R2） |
| 3.6 | 受控构造策略 A 失败（临时构建强制 FillViaAx 失败） | 自动降级 B；跳转成功且剪贴板恢复 |
| 3.7 | 受控构造策略 B 也超时 | 浮层重现并显示「路径已复制，按 ⌘⇧G 后 ⌘V 粘贴」；路径仍在剪贴板 |
| 3.8 | 跳转进行中切到别的 app 并保持到结果返回 | 不在无关 app 上方重现提示（N1） |
| 3.9 | Go-to 框预填内容后触发降级 | 观察是否出现「旧值+路径」拼接（L3） |
| 3.10 | 慢应用/大目录下跳转 | 观察读回重试预算是否误判 FellBack（L4） |
| 3.11 | 连续跳转 20+ 次 | 无崩溃、无明显内存增长（L8 后台线程剪贴板调用） |

## 7. 遗留项登记（不阻塞合并，实机时重点核对）

| 项 | 说明 |
|---|---|
| 多类型剪贴板快照 | 当前仅纯文本；`restore(None)` 会清非文本项。富文本/图片/文件场景记录实际丢失（L1） |
| `clipboard_set_text` 失败边角 | 极罕见；「路径已复制」文案可能失真（L2） |
| ⌘V 追加风险 | 策略 A 部分生效后转 B，最坏残留「旧值+路径」；不误保存（L3） |
| 读回预算 | 初次 +2 次重试/50ms；慢应用可能误判 FellBack（L4） |
| 滚动跟随 | 无回归钉，实机确认（L5） |
| 探针/navigator 定位逻辑重复 | Task 15 共享化候选（L6） |
| 窗口补丁状态重复 | WindowPatchState 抽取候选（L7） |
| AXFloatingWindow 白名单 | M0 实测后修订特征表（L9） |
| daemon 在线缓存 | 全隐期最坏陈旧 30s（L11） |
| R2 首次 Shown 被去重 | `daemon_online=false` 或 `overlay_show` 失败时，同面板后续 Shown 被抑制；实机确认是否可接受 |
