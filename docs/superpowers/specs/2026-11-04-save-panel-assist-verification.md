## 0. 实机验证结论（2026-11-05，已通过项）

实机暴露并已修复的问题（对应 commit）：

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | detector 启动即失败 `AXObserverCreate 失败` | 启动用 pid=0 占位创建 observer，AX 拒绝 | observer 延后到首个真实前台 pid 创建（a4a879a） |

| 7 | 中文输入法无法上屏（空格/数字作为普通键进入） | 浮层每帧 `request_focus` → egui `interrupt_ime()` 每帧打断组合，marked text 被清、Commit 丢失 | 仅在未聚焦时请求焦点（8e53b22）；winit 取证见 MCE_APP_LOG 诊断工具（299c72d） |

已通过项：主链路（浮层出现 → 目录搜索 → Enter → 面板跳到目标目录，策略 A 直设成功）、跳转后浮层不复现、Esc 关闭与本次面板内屏蔽、点击浮层保持、中文输入法上屏、Finder 显示简介（⌘I）不误报、深浅主题跟随（浮层开着切外观即时换色）、宽度 600 + 新输入提示、长路径显示（~ 压缩 + 中段省略 + 悬停全路径）。

## 0. 环境准备

1. 关闭旧实例与 daemon（托盘退出；必要时 `pkill -f macEverything`）。
2. `cargo build --release && bash scripts/bundle.sh`，`open release/macEverything.app`。
3. `./target/release/macEverything status` 确认 daemon 在线；`save_panel_assist` 默认 false（实验功能，需手动开启）。
4. 系统设置 → 隐私与安全性 → 辅助功能，授权 **release/macEverything.app**（ad-hoc 重打包会改变签名身份，每次重打包需重新确认授权）。
5. 日志：`log stream --predicate 'process == "macEverything-app"' --info`。

## 1. M0 探针验证（独立于产品链路）

前置：设置里先关掉「保存面板目录助手」开关，避免产品 detector 与探针同时作用。

2. `MCE_PANEL_PROBE=1 ./target/debug/macEverything-app 2>&1 | tee /tmp/probe.log`（给 debug 二进制授权）
3. `echo "clip-content" | pbcopy` 预置剪贴板

| ③ | post-to-pid：日志区分「⌘⇧G 未生效（焦点仍在 AXTextField）」与「3s 内未定位」 | |
| ⑤ | 输入框定位：`Go-to 输入框已定位`；EDITABLE 值 | |
| ⑥ | 前往按钮 vs Return：按钮 title/desc dump；AXPress 或 Return 哪条生效 | |
| ⑦ | 后台线程 AX 调用无崩溃/无错误 | |
