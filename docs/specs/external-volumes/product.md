# 外接磁盘索引 v1 产品规格

- 日期：2026-10-21
- 状态：已评审（维护者确认三决策，见 §2）
- 关联：`docs/specs/v1-core/product.md` §1（扫描范围）、`docs/development.md`

## 1. 目标与范围

外接磁盘（USB / 雷电 / SD / 内置多分区等**本地卷**）插入后自动纳入搜索，
拔出后索引即清除。对标 Windows Everything 的「可移动驱动器」体验。

**包含**：本地外接卷的自动发现、索引、实时监听、拔出清除、设置开关。
**不包含**（后续版本）：网络卷（SMB/NFS/AFP/WebDAV）、Time Machine 卷、
按卷增量优化（重插即全量重扫该卷）、卷 UUID 键控（v1 按卷目录名键控）。

## 2. 已确认决策（2026-10-21）

| 决策 | 选择 | 备注 |
| --- | --- | --- |
| 插入行为 | **默认自动索引** | 无需任何操作；设置里可按卷关闭 |
| 网络卷 | **本版不做** | FSEvents 不可用需另做轮询，复杂度翻倍 |
| 拔盘策略 | **拔盘即清除** | 重插全量重扫该卷；不做「标离线保留」 |

## 3. 用户可见行为

1. 插入本地外接盘 → 数秒内后台开始索引（不阻塞搜索，主索引已就绪可查）；
   完成后该卷文件可被搜到，路径形如 `/Volumes/<卷名>/...`。
2. 拔出（或推出）该卷 → 该卷条目从搜索结果消失（下次查询即不含）。
3. 设置 → 「外接磁盘」分组：
   - 主开关「自动索引外接磁盘」（默认开）：关闭后清除全部卷条目并不再自动挂；
   - 当前挂载的本地卷列表，每卷一个开关（关闭 = 从索引移除该卷并记住，
     重插不再自动索引；重新打开 = 立即索引该卷）。
4. App 重启：上次挂着的卷仍在 → 索引延续（停机窗口事件重放追平）；
   已拔的卷 → 其条目在启动清理中移除，不进搜索结果。

## 4. 非功能约束

- 卷扫描不阻塞主索引的「就绪」状态与查询（挂载扫描在后台线程）。
- 拔盘的竞态安全：扫描进行中拔盘 → 扫描批次间检测卷目录消失即中止并清除。
- 隐私与网络：卷索引不发起任何网络请求；网络卷从不触碰（§1）。
- 排除规则（`excluded`）对卷内路径同样生效（共用 `scanner::is_excluded`）。
