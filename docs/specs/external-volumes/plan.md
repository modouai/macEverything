# 外接磁盘索引 v1 实施计划

- 日期：2026-10-21
- 关联：`product.md` / `tech.md`

## 切片

1. **引擎**：`index::remove_prefix`（前缀墓碑 + dir_map 清理）+ 单测（突变验证：
   改坏前缀匹配即红）。
2. **daemon 卷监听**：`VolumeMonitor`（3s 轮询 /Volumes + statfs 判定 + 对账）；
   启动期并入期望卷 roots + 清除未挂载卷前缀；运行期挂载 = 后台扫描 + 按卷流 +
   consume 线程；卸载 = 清除 + 停流；`config` 新字段读取。
3. **协议 + 设置页**：`SetVolumePrefs` 消息（protocol 编解码 + daemon 处理 +
   client 封装）；设置页「外接磁盘」分组（主开关 + 挂载卷列表开关，App 侧
   `read_dir /Volumes` + `statfs` 列卷，不经 daemon）。
4. **文档 + 发版**：README/usage 行为说明；实机验收（插拔 U 盘：挂载索引、
   搜索命中、拔出清除、重插重扫、开关即时生效）；发版 2.4.0。

## 实机验收清单

- [ ] 插入 U 盘 → 状态从 READY 转 RECONCILING/BUILDING？**否**——卷扫描不动主状态位，
      daemon.log 出现「卷挂载,开始索引」与完成条数；期间搜索正常。
- [ ] 搜卷内文件名可命中，路径 `/Volumes/<名>/...`。
- [ ] 拔盘 → 下次查询无该卷条目；daemon.log「卷卸载,清除 N 条」。
- [ ] 重插 → 全量重扫该卷，恢复命中。
- [ ] 设置关闭单卷 → 条目消失，重插不自动索引；重新打开 → 立即索引。
- [ ] 关闭主开关 → 全部卷条目消失。
- [ ] App 重启（卷挂载中）→ 搜索命中卷内文件（停机窗口变更被重放追平）。
- [ ] App 重启（卷已拔）→ 卷条目不在结果中（启动清除生效）。
- [ ] fmt/clippy/test 全绿；三门禁外另跑既有实机链路（FSEvents live）。
