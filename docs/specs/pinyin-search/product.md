# 拼音搜索（全拼）产品规格

- 日期：2026-11-15
- 状态：已确认（待实现）
- 关联：设计 `docs/superpowers/specs/2026-11-15-pinyin-search-design.md`；实现计划
  `docs/superpowers/plans/2026-11-15-pinyin-search.md`

## 1. 功能与范围

纯 ASCII 全拼查询词直接命中中文条目名称（文件与文件夹，与字面匹配同口径）：
`shu` → 数/书/树，`shuxue` → 数学，`shux`（未打完的末音节）→ 数学。

- **默认开启，无开关**：没有配置项可关闭。单次查询可用 `case:` / `whole:` 规避，
  代价是同时改变字面匹配：`case:` 令字面区分大小写，`whole:` 令字面变为整词。
  不提供仅关闭拼音的选项。
- **查询侧展开**：拼音在查询时展开为汉字字符集，索引内存布局与落盘格式零改动；
  旧索引直接可用，无迁移。查询侧反查表懒构建，常驻约 400KB（shrink 后，首次纯字母查询词触发）。
- **全客户端自动生效**：实现位于 engine 查询层，CLI 与 GUI 经 daemon 获得同一行为，
  protocol 不变。
- **逐键输入稳定（设计目标 4，手动核对）**：GUI 60ms 防抖下结果连续、打字过程不闪烁；
  以手动 GUI 核对为准，不作自动门禁。单字母查询的短暂噪音属已知局限（§3 第 4 条）。

非目标：

- **首字母匹配**（`sx` → 数学）：歧义集合过大，查询侧展开不可行。设计边界为其预留；
  将来实现时替换匹配层并新增索引侧读音序列（另立规格）。
- 索引侧拼音预存（Spotlight 式读音标注）。
- 混合词（`数xue`）、通配符词（`shu*`）、`whole:` 词的拼音展开。
- 日文假名、韩文等非汉字表音文字的读音匹配。
- 配置开关（默认开启，不提供关闭项）。

## 2. 启用条件与命中语义

### 2.1 启用条件

「整轮」= 作用于整个查询、与书写位置无关（`docs/usage.md` 称「本轮」）。一个条目
名称词（`path:` 之外的词）同时满足以下条件才编译拼音分支；任一不满足即维持纯字面
匹配，无提示、无错误：

| # | 作用域 | 条件 | 说明 |
|---|---|---|---|
| 1 | 整轮 | 非 `case:`、非 `whole:` | `case:` 是精确意图，拼音是模糊召回，不叠加 |
| 2 | 词级 | 词不含 `*` / `?` | 实现门控见 `tech.md` §1.2 |
| 3 | 词级 | 词只含 ASCII 字母与 `'`，且至少一个字母 | 小写折叠后判定；`Shu` 与 `shu` 同。数字与其他符号出现即不展开；空格是分词符，各词独立判定 |
| 4 | 词级 | 词能切分为合法音节序列（§2.2） | 否则静默回退纯字面 |
| 5 | 词级 | 词不是 `path:` 词 | 路径词恒不展开 |

### 2.2 切分

- 音节表：由读音数据派生（ASCII 完整读音 419 个，含 `hm`/`hng`/`m`/`n` 等叹词音节；
  `ü` 记作 `v`）。派生而非硬编码保证切分表与字符集同源：完整音节不会切出读音数据里
  不存在的音节。字符集按前缀建，完整音节段仍按前缀召回（§2.3）。
- **完整音节全枚举、最长音节优先**：每段为完整音节（末段可为任意音节前缀），全部
  可行切分参与命中（OR）。歧义切分是真实需求：`fangan` 同时命中方案（fang+an）与
  反感（fan+gan）；`xian` 同时命中先（xian）与西安（xi+an）。
- `'` 为强制分段边界：边界两侧各自单独切分，边界内仍全枚举。`xi'an` 至少产出
  `[xi][an]`，另有 `[xi][a][n]`（`a`、`n` 都是完整音节）；没有任何方案跨过边界。
- 可行切分超过 8 种时截断取前 8 种（最长优先顺序），防御组合爆炸。
- 无任何可行切分（`pdf`、`shuxq`）→ 不展开。

| 查询词 | 切分 |
|---|---|
| `shu` | `[shu]` |
| `shuxue` | `[shu][xue]`、`[shu][xu][e]` 等 |
| `shux` | `[shu][x]`（末段前缀） |
| `sh` | `[sh]`（末段前缀） |
| `fangan` | `[fang][an]`、`[fan][gan]`、`[fa][n][gan]` 等（上限 8 种） |
| `xi'an` | `[xi][an]`、`[xi][a][n]` 等 |
| `pdf` | 无可行切分 → 不展开 |
| `dot` | 无可行切分（`do` 非完整音节、`dot` 非任何读音前缀）→ 不展开 |

### 2.3 读音与字符集

- 去声调；`ü` 归一为 `v`（`lv` → 绿/律，主流 IME 习惯）。`数` 的 shǔ/shù 两种声调
  归并为 `shu`（shuò 作为另一读音保留为 `shuo`）。
- 多音字任一读音参与：`长`（cháng/zhǎng）同时在 `chang` 与 `zhang` 集；`行`
  （xíng/háng）同时在 `xing` 与 `hang` 集。
- 字符集按**读音前缀**建，完整音节段与其他段共用同一规则：前缀 `sh` 的集 = 任一读音
  以 `sh` 开头的全部汉字；完整音节 `shu` 的集 = 任一读音以 `shu` 开头（shu/shui/
  shuang/shuo/…）的全部汉字。因此 `shu` 既命中 数/书/树，也命中 水（shui）/双
  （shuang）/说（shuo）；`shuxue` 可命中「水学」「双学」类组合。这是 IME 候选式的
  召回语义（已知局限 §3 第 7 条）。
- 字符域：CJK 统一表意文字基本区 U+4E00–U+9FFF。扩展区与兼容区汉字不直接参与；
  名称在匹配前经 NFC 归一，可归一到基本区的兼容汉字（如 U+F900）会以归一后字符参与
  （边缘情形）。

### 2.4 命中语义

- 拼音命中 = 条目名称中存在**连续**汉字序列，逐字归属对应音节的字符集（第 i 字 ∈
  第 i 段集）。字符集之间不允许插入其他字符：`数-学` 不被 `shuxue` 命中。
- 命中位置任意：`shu` 命中「报告书」，也命中目录「数学资料」。
- 拼音命中按前缀集召回，比同音精确匹配宽：`shu` 也命中 水/双/说（§2.3）。
- 命中选择：一个字面匹配 OR 拼音匹配任一成立即命中；多个切分方案任一成立即命中。
- 拼音分支与字面匹配同数据源（条目名称），CJK 字节不受小写折叠影响。
- 全 ASCII 条目名称不参与拼音匹配（快速路径，也避免把英文名误判为可拼读）。

### 2.5 评分

沿用现有相关度档位（3 = 名称开头命中，2 = 字面整词边界，1 = 子串）：

- 拼音命中起点在名称首字符 → 最终可升到档 3。
- 拼音命中起点在名称中部 → 不升档（保持字面档，通常为 1）。
- 最终取字面与拼音较高档；档 2 只来自字面匹配，拼音只可能把结果升到 3。

效果：查 `shu` 时「数学.pdf」（拼音开头）排在「季度报告书.docx」（拼音中部）之前。

### 2.6 与现有语法的交互

| 查询 | 拼音展开 |
|---|---|
| `shu` | ✓ |
| `shuxue` | ✓ |
| `shux` | ✓（末段前缀） |
| `xi'an` | ✓（强制边界） |
| `Shu` | ✓（折叠后纯字母） |
| `case:shu` / `case:README` | ✗（整轮） |
| `whole:shu` | ✗ |
| `shu*.pdf` / `*shu` | ✗（含通配符） |
| `path:shu` | ✗ |
| `数xue`（混合词） | ✗（词含非字母） |
| `dot` | ✗（切分失败，见 §2.2） |
| `pdf` | ✗（无可行切分） |

## 3. 已知局限

1. 首字母不支持（`sx` 不命中数学）。设计边界为其预留：将来实现时替换匹配层并新增
   索引侧读音序列（另立规格）。
2. `xian` 同时匹配先与西安（全切分 OR）；`xi'an` 只强制该处边界，边界内仍子切分
   （仍可能按 `[xi][a][n]` 命中三字序列），不保证只命中两字词。
3. 混合词（`数xue`）不展开；`whole:` 与通配符词不展开。
4. 单字母查询（`s`）集合达数千字，结果噪音大；逐键输入时短暂出现，属可接受行为。
5. 仅 CJK 基本区汉字直接参与；经 NFC 归一后落入基本区的兼容汉字可能参与（边缘）。
6. `ü` 只接受 `v` 写法（`lv` → 绿），不接受 `lü`（与主流 IME 一致）。
7. 完整音节段使用前缀集，召回偏宽：`shu` 也命中 水/双/说，`shuxue` 可命中「水学」
   「双学」类组合（IME 候选式语义）。
8. 输入防护：查询词需为 ASCII 且 ≤64 字节，切分搜索步数预算 10000，超限静默回退
   字面匹配（与设计 §3.2/§8 一致；实现细节见 `tech.md` §2.3）。

## 4. 验收标准

| 场景 | 查询 | 期望 |
|---|---|---|
| 全拼基本 | `shu` | 命中含 数/书/树 的条目名称（任意位置） |
| 前缀集召回 | `shu` / `shuxue` | `shu` 同时命中 水/双/说（shui/shuang/shuo）；`shuxue` 可命中「水学」「双学」类组合（已知局限 §3 第 7 条） |
| 未打完 | `shux` | 命中「数学」 |
| 末段单字母 | `sh` | 命中读音以 `sh` 开头的条目（末段前缀） |
| 完整音节 | `shuxue` | 命中「数学」 |
| 强制边界 | `xi'an` | 命中「西安」（`[xi][an]`）；不按单音节 `[xian]` 命中「先」；`[xi][a][n]` 可命中三字序列，不保证只命中两字词 |
| 歧义切分 | `fangan` | 命中「方案」与「反感」（多切分 OR） |
| 歧义切分 | `xian` | 命中「先」与「西安」 |
| 折叠 | `Shu` | 与 `shu` 同（折叠后展开） |
| ü 归一 | `lv` | 命中 绿/律 |
| 多音字 | `chang` / `zhang` | 均命中「长」 |
| 多音字 | `xing` / `hang` | 均命中「行」 |
| 目录 | `shu` | 命中目录「数学资料」（条目名称含目录，与字面同口径） |
| 排序 | `shu` | 「数学.pdf」排在「季度报告书.docx」前（前缀档 3 > 中部档 1） |
| 英文名 | `shu` | 仍字面命中 `shu.txt`；全 ASCII 名称不参与拼音匹配 |
| 语法互斥 | `case:shu` / `whole:shu` / `shu*.pdf` / `*shu` / `*shu*` / `path:shu` / `数xue` / `dot` / `pdf` | 不展开（§2.6 逐行） |
| 索引 | 任意 | 索引内存布局与落盘无变化；旧索引直接可用；`parity` 不受影响 |
| 门禁 | — | fmt / clippy / test 全绿；新增测试经突变验证 |

逐键输入的「结果连续、不闪烁」为设计目标 4 的手动 GUI 核对项，不作自动门禁。
