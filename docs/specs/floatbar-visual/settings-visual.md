## 二、设置窗口

### 2.1 窗口

| 属性 | 值 |
|---|---|
| 尺寸 | **620 × 600**（固定，不随内容或屏幕缩放） |
| 画布位置 | 1280 × 800 桌面上居中：x = 330，y = 117 |
| 圆角 / 描边 | 12 / 1px 内描边 |
| 底 | 深 `#1A1D22` / 浅 `#FFFFFF` |
| 阴影 | 偏移 (0, 30)，模糊 70，扩展 −10；深 `#000000B3` / 浅 `#1E293B38` |
| 标题栏 | 高 44，左右内边距 20；交通灯 3 × 12、间距 8；标题「设置」13pt 居中 |
| 内容区 | 左右内边距 24，上下 20；分组间距 20 |

### 2.2 结构树

```
Settings Window (620×600, 纵向)
├── Title Bar (44)
│   ├── Traffic Lights (3 × 12, 间距 8)
│   ├── Window Title「设置」13pt (弹性宽, 居中)
│   └── Right Spacer (52)
└── Content (弹性高, 纵向, padding [20,24], gap 20)
    ├── 外观
    │   ├── Header 12pt
    │   └── Card → 字号 Row
    ├── 通用
    │   ├── Header 12pt
    │   └── Card → 开机自启 / 语言 / 唤起快捷键 / 完整窗口快捷键
    └── 索引
        ├── Header 12pt
        └── Card → 排除目录 Header + 3 × Excluded Dir Row
```

### 2.3 分组卡片与行

| 属性 | 值 |
|---|---|
| 分组标题 | 12pt，次要色；与卡片间距 8 |
| 卡片 | 圆角 10，底 `#FFFFFF0A` / `#00000005` |
| 行高 | 44（排除目录 Header 52，目录行 40） |
| 行内边距 | 左右 16；标签与控件间距 16，垂直居中 |
| 分隔线 | 1px，行与行之间 |
| 标签 | 13pt 主要色；辅助说明 11pt 次要色，与标签间距 2 |

### 2.4 设置项

| 分组 | 行 | 控件 | 规格 |
|---|---|---|---|
| 外观 | 字号 | 三段选择 | 容器 180 × 28、圆角 7、padding 2、间距 2；段圆角 6，12pt；选中「标准」 |
| 通用 | 开机自启 | 开关 | 38 × 22、圆角 11；开态系统蓝；钮 18 × 18 白色，带 1px 柔和投影 |
| 通用 | 语言 | 下拉按钮 | 152 × 28、圆角 7；文字「简体中文」13pt + `chevron-down` 14 |
| 通用 | 唤起快捷键 | 键帽字段 | 152 × 28、圆角 7；键帽 `⌥` `Space`（高 20、圆角 4、11pt） |
| 通用 | 完整窗口快捷键 | 键帽字段 | 同上；键帽 `⌥` `⇧` `F` |
| 索引 | 排除目录 | 添加按钮 + 目录列表 | 按钮高 28、圆角 7：「＋ 添加目录…」12pt；目录行 40，文件夹图标 16 + 路径 13 + 移除 × 14 |

**示例内容**（原型示意，不是真实默认值）：

| 项 | 示意值 |
|---|---|
| 字号 | 标准（小 / 标准 / 大） |
| 语言 | 简体中文 |
| 快捷键 | `⌥ Space` / `⌥ ⇧ F` |
| 排除目录 | `~/Library/Caches`、`~/Movies/素材库`、`~/node_modules` |

**行为**：

- 设置项修改后立即生效，不设保存 / 取消按钮。
- 添加目录调用系统目录选择器；移除即时生效。原型只画静止列表。
- 快捷键字段点击后进入录制；录制中、冲突提示不在本次原型范围。
- 语言切换的生效时机、排除规则对索引的影响，由 v2.1 产品 / 技术规格定义，本文不预设。

> **v2.1 快捷键实现状态（2026-10-18）**：键帽字段已接线录制——空闲显示运行时快照的
> 实际注册键帽；点击后（suspend 同步完成）显示「按下快捷键…」，行下显示可见提示
> 「按 Esc 或点击别处取消」。Esc、再次点击、点击字段外、失焦/最小化、关闭窗口
> （⌘W/红点）均取消并恢复旧键（录制期全局热键挂起）。⌘C/⌘X/⌘V（剪贴板事件）
> 可录制；非法组合、与另一槽重复、系统占用、保存失败显示红色行内错误；启动回落
> 提示按槽显示在对应行下方。错误/回落提示/录制提示可同时存在（各占一行），通用
> 卡片高度随 `RowSpec.extra` 增高，620×600 固定窗内整页滚动。排除目录仍待实现。

## 三、入口

### 3.1 完整结果窗口 · 标题栏齿轮

| 属性 | 值 |
|---|---|
| 位置 | 标题栏右端，与交通灯同一行；标题栏改为两端对齐 |
| 按钮 | 28 × 28，圆角 7，静止态无底 |
| 图标 | Lucide `settings` 16 × 16；深 `#C6CBD1` / 浅 `#4B5563` |
| 悬停 | 底 `#FFFFFF1F` / `#0000000F`（实现态，原型未画） |
| 提示 | tooltip「设置」 |
| 点击 | 打开设置窗口（同一实例，不重复打开） |

两套主题的完整结果窗口都已加入该按钮（深 `nukBl` / 浅 `N8THjX`）。标题栏高度、交通灯位置不变。

> **v2.1 Phase A 实现状态（2026-10-18）**：齿轮按钮按本节尺寸/图标/悬停/tooltip 落地；
> 点击打开设置窗口（同一实例，隐藏=关闭）。设置窗为 eframe **deferred 子视口**：
> 原生交通灯 + fullsize content + 自绘 44px 标题栏的 PoC **已验证**，无回落原生标题栏的
> 偏差；620×600 固定，首次打开按光标所在屏居中，之后只置前并保留用户位置。

### 3.2 托盘菜单 · 「设置…」

- 菜单项追加在「开机自启」之后、「退出」之前；带省略号，表示打开窗口。
- 点击后关闭菜单并打开设置窗口；主窗口未打开时同样可用。
- 托盘菜单是**系统原生菜单**，菜单项文案与顺序见第四节；实际观感随 macOS 系统外观。

> **v2.1 Phase A 实现状态（2026-10-18）**：菜单项与分组（状态 / 打开 / 自启 + 设置 /
> 退出）已按 §4.2 落地，含三组分隔线；「设置…」打开同一设置窗口实例。ROOT 隐藏
>（**同 Space**）时已实机验证可把设置窗带到前台（原生 `activate` +
> `orderFrontRegardless` + `makeKeyWindow`，最小化态先 `deminiaturize`）；
> **跨 Space 待验**（未额外设置 `collectionBehavior`）。权限缺口项按 `product.md` §3
> 在有缺口时动态追加（原型未画）。

## 六、已知说明

1. **实现状态（v2.1 Phase A，2026-10-18）**：设置窗口 620×600、字号三档、开机自启、
   语言占位已实现；快捷键录制与排除目录为独立计划（`plan-hotkeys.md` /
   `plan-exclusions.md`），本期未实现。
2. **子视口标题栏 PoC 已验证**：eframe deferred 子视口 + 透明标题栏 +
   `fullsize_content_view` 下原生交通灯正常浮于自绘 44px 标题栏；标题栏拖拽、红点、
   ⌘W 隐藏均可用，无需回落原生标题栏。
3. **滚动模型**：内容超出可视高时**整页纵向滚动**，44px 标题栏固定；排除目录列表
   随整页滚动，不做卡片内独立滚动（大字号下同一行为）。
4. **开机自启审批态**：若系统要求用户允许，`RequiresApproval` 按**关态**显示 +
   行内提示「已注册,待系统设置「登录项」允许」；托盘同样不勾选（登录时不会拉起）。
   注册/注销后以 `SMAppService` 的真实状态为准，不用请求值反推。
5. **托盘菜单是原生菜单**：原型为近似绘制，实际字体、材质、阴影随系统；只画深色一屏。
6. **菜单层级**：`原型.pen` 中菜单是屏幕级浮层（与菜单栏同级），保证布局稳定；产品中它属于菜单栏托盘图标。
7. **未定义项**：语言切换生效时机、排除目录对索引的具体影响、快捷键冲突处理，均留待
   对应独立计划的产品 / 技术规格。
8. **待复核**：托盘「开机自启」勾选视觉与设置页的一致性仍待 controller 实机复核；
   跨 Space 唤起设置窗同样待验（本期只验证了同 Space）。
9. **最小化恢复**：设置窗最小化时，齿轮/托盘路径先 `deminiaturize` 再
   `orderFrontRegardless` + `makeKeyWindow`；完整窗口唤起同步补齐该守卫。
